# teash resource pack

Server: **teash.mooo.com**

Minecraft Java 1.21.11–26.2. Download the ZIP from Releases and put it into your client's resourcepacks directory.

The pack contains the supplied weapon assets, teash branding, 15 pixel rank badges and a burgundy boss bar. Some original custom weapon models were absent in the supplied source and currently use vanilla appearances. Menu labels are customized; a resource pack cannot change button actions.

Credits: supplied rank artwork and weapon resources retain their original authorship; TikTok badge and teash icon prepared for this server. No exclusivity or ownership of third-party artwork is claimed.
